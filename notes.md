# What to read
Fluent Python, 2nd Edition (O'Reilly Media, Inc.)  
1: The Python Data Model - Special methods like __repr__ and __len__, which let your own objects work with built-ins like print and len. - If you had a stock quote object, how should it look when printed, and which special method controls that?  

5: Data Class Builders - Short ways to make classes that mainly hold data, like dataclass and NamedTuple. - What would you use to hold a ticker, price and day change, and why that one over the others?  

8: Type Hints in Functions - How to label function inputs and outputs, as you did with -> None. - What should a function that fetches a quote return, including when the ticker doesn’t exist?
